# Minjoon Choi — Portfolio

Scroll-driven portfolio website inspired by the spatial browsing experience of The HTML Review Issue 04.

## Development

```bash
pnpm install
pnpm dev
```

## Checks

```bash
pnpm run build
pnpm run lint
```

Every push to `main` runs an automated build check in GitHub Actions. Deployment will be configured separately after the portfolio is complete.

## Current status

- Header and footer structure
- Fixed viewport project stage
- Scroll-driven layered project cards
- Responsive mobile layout
- Reduced-motion support

Project names, descriptions, links, and media are placeholders for now.
